## 🛠️ 도구

게임 사이 쉬어가는 무료 생활 도구도 만듭니다.

- 🔮 **[운세가 궁금하지?](https://mindweaver74.github.io/fortune/)** — 생년월일로 보는 오늘의 운세 + 행운의 로또 번호. 매일 바뀌는 나만의 운세 카드를 이미지로 저장해 공유하세요.

## ⚡ 만드는 방식

- **순수 HTML5 / CSS / JavaScript** — 프레임워크·빌드 도구 없이 단일 파일로 완결
- **모바일 우선** — 터치 조작, 세로 화면, 인앱 브라우저까지 고려
- **오프라인 동작** — 외부 의존성 없이 어디서든 열리는 게임
